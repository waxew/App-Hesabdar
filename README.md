# حسابدار (App-Hesabdar)

نرم‌افزار حسابداری فارسی اندروید با رویکرد Offline-First و دیتابیس کاملاً محلی. هدف پروژه ساخت یک هسته حسابداری مستقل و قابل‌گسترش در کلاس نرم‌افزارهای حسابداری عمومی است؛ طراحی، کد و رابط کاربری این پروژه مستقل هستند.

## وضعیت فعلی

- نسخه: `0.10.0 Beta`
- `versionCode = 5`
- `applicationId = com.waxew.hesabdar`
- Kotlin + Jetpack Compose + Material 3
- Room + SQLite
- `minSdk = 24`
- `targetSdk = 35`
- رابط فارسی و RTL
- تاریخ شمسی داخلی
- بدون وابستگی اجباری به اینترنت یا سرور

## ساختار دیتابیس

Room Schema فعلی نسخه `4` است و شامل جداول اصلی زیر است:

- `persons`
- `products`
- `invoices`
- `invoice_items`
- `payments`
- `inventory_movements`
- `treasury_accounts`
- `ledger_accounts`
- `journal_documents`
- `journal_lines`
- `checks`
- `installments`
- `cash_entries`
- `audit_logs`

Migrationهای `1 -> 2`، `2 -> 3` و `3 -> 4` صریح هستند و داده‌های نسخه‌های قبلی را حذف نمی‌کنند.

## اصول توسعه غیرقابل‌تغییر

1. اطلاعات اصلی کاربر داخل گوشی ذخیره می‌شود.
2. برای مبالغ مالی از `Long` استفاده می‌شود، نه `Float` و `Double`.
3. هر تغییر Room Schema باید Migration صریح داشته باشد.
4. در Production از `fallbackToDestructiveMigration` استفاده نمی‌شود.
5. `applicationId` ثابت می‌ماند تا نسخه‌های جدید روی نسخه قبلی نصب شوند.
6. عملیات چندجدولی مالی Atomic و Transactional هستند.
7. فاکتور و عملیات مالی از Repository/Engine مرکزی عبور می‌کنند.
8. تاریخچه مالی با Audit Trail قابل ردیابی نگه داشته می‌شود.
9. Keystore خصوصی Release داخل Repository عمومی Commit نمی‌شود.
