# حسابدار (App-Hesabdar)

نرم‌افزار حسابداری تخصصی اندروید با رویکرد Offline-First و دیتابیس کاملاً محلی. هدف پروژه ساخت یک هسته حسابداری مستقل و قابل‌گسترش در کلاس نرم‌افزارهای حسابداری عمومی مانند هلو و پارمیس است؛ بدون کپی کد یا رابط کاربری آن‌ها.

## وضعیت فعلی

- نسخه توسعه: `0.1.0`
- `versionCode = 1`
- `applicationId = com.waxew.hesabdar`
- Kotlin + Jetpack Compose + Material 3
- Room + SQLite برای ذخیره‌سازی محلی
- `minSdk = 24`
- `targetSdk = 35`
- رابط فارسی و راست‌به‌چپ

نسخه `0.1.0` نسخه Foundation است: اسکلت واقعی اپ، دیتابیس Room، داشبورد اولیه، اشخاص و کالاها. ماژول‌های مالی به‌صورت مرحله‌ای روی همین هسته اضافه می‌شوند.

## اصول ثابت پروژه

1. اطلاعات اصلی کاربر داخل گوشی ذخیره می‌شود و برای کارکرد پایه اینترنت لازم نیست.
2. مبالغ مالی با `Long` ذخیره می‌شوند؛ برای پول از `Float` و `Double` استفاده نمی‌شود.
3. هر تغییر Schema باید Migration مشخص داشته باشد.
4. در نسخه Production از `fallbackToDestructiveMigration` استفاده نمی‌شود.
5. نسخه جدید باید روی نسخه قبلی نصب شود و اطلاعات کاربر حفظ شود.
6. عملیات مالی چندمرحله‌ای باید Atomic باشد و داخل Transaction انجام شود.
7. فاکتور، انبار، دریافت/پرداخت و سند حسابداری در نهایت از یک Accounting Engine مرکزی عبور می‌کنند.
8. کدهای پروژه همراه توضیح و کامنت نگهداری می‌شوند تا وظیفه فایل‌ها و بخش‌های مهم مشخص باشد.

## Build

در GitHub Actions یک APK دیباگ قابل نصب ساخته می‌شود. Workflow بعد از آماده شدن اسکلت کد فعال خواهد شد.

## سیاست انتشار

- `applicationId` ثابت می‌ماند.
- `versionCode` در هر انتشار افزایش می‌یابد.
- Release نهایی با Keystore ثابت امضا می‌شود.
- فایل Keystore خصوصی داخل Repository عمومی Commit نمی‌شود.
- قبل از هر Migration روی داده‌های واقعی تست Backup/Restore و Upgrade انجام می‌شود.
